# Java Projects by fikriaf

Selamat datang di repositori **Java** ini. Repositori ini berisi berbagai proyek dan contoh kode yang telah saya kembangkan menggunakan bahasa pemrograman Java.

# Daftar Proyek
### 1. Basic
**Deskripsi:**  
Proyek ini mencakup konsep dasar pemrograman Java, seperti struktur kontrol, tipe data, dan sintaks dasar lainnya.

**Fitur Utama:**
- Implementasi struktur kontrol dasar
- Penggunaan array dan koleksi
- Contoh penggunaan metode dan kelas

### 2. Cars
**Deskripsi:**  
Sebuah aplikasi sederhana untuk manajemen data mobil, termasuk informasi seperti merek, model, tahun, dan harga.

**Fitur Utama:**
- Menambahkan, mengedit, dan menghapus data mobil
- Menampilkan daftar mobil yang tersedia
- Pencarian mobil berdasarkan kriteria tertentu

### 3. Library
**Deskripsi:**  
Proyek ini merupakan simulasi sistem manajemen perpustakaan untuk mengelola data buku dan anggota.

**Fitur Utama:**
- Menambahkan dan menghapus buku dari katalog
- Registrasi dan manajemen data anggota perpustakaan
- Peminjaman dan pengembalian buku

### 4. mavenproject1
**Deskripsi:**  
Proyek ini menggunakan Apache Maven untuk manajemen dependensi dan build otomatis. Fokus pada konfigurasi dasar Maven dan struktur proyek.

**Fitur Utama:**
- Konfigurasi file `pom.xml`
- Struktur direktori standar Maven
- Contoh penggunaan dependensi pihak ketiga

### 5. mavenproject2
**Deskripsi:**  
Melanjutkan eksplorasi Maven dengan menambahkan plugin dan profil build yang lebih kompleks.

**Fitur Utama:**
- Penggunaan plugin Maven untuk tugas otomatisasi
- Definisi profil build untuk lingkungan yang berbeda
- Integrasi dengan alat pengujian

### 6. pertem6
**Deskripsi:**  
Materi dan contoh kode dari pertemuan ke-6 dalam kursus atau pelatihan Java yang saya ikuti.

**Fitur Utama:**
- Topik yang dibahas pada pertemuan ke-6
- Contoh kode dan implementasi terkait

### 7. tes.java & tes.class
**Deskripsi:**  
File `tes.java` adalah kode sumber Java untuk pengujian atau eksperimen tertentu, sedangkan `tes.class` adalah hasil kompilasi dari file tersebut.

**Fitur Utama:**
- Eksperimen dengan fitur atau konsep Java tertentu
- Pengujian fungsi atau metode spesifik
